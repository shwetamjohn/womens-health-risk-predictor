About the Dataset

Wisconsin Breast Cancer Dataset (UCI Machine Learning Repository)

Data Overview

699 patient samples collected from fine needle aspirates (FNA) of breast masses at the University of Wisconsin Hospital.

458 Benign (65.5%) 241 Malignant (34.5%)

Feature Scale

All 9 clinical features are rated on a scale of 1–10, where 1 is closest to normal and 10 is the most abnormal.

1 = Normal 10 = Abnormal

Model Performance

Logistic Regression, Random Forest, SVM, KNN, and Gradient Boosting all trained and compared. Best model achieves 97%+ accuracy.

97%+ Accuracy 0.98+ ROC-AUC

How It Works

From raw clinical data to risk prediction in milliseconds

01

Input Cell Features

Enter 9 clinical measurements from a fine needle aspirate biopsy, each scored 1–10.

02

Feature Scaling

Values are normalized using the same StandardScaler parameters from model training.

03

ML Prediction

The trained Logistic Regression model computes a probability score for malignancy.

04

Risk Classification

Result is classified as Benign or Malignant with a confidence percentage.
